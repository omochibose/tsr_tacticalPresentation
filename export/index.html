  • データパイプラインは、収集 → 整形 → 保存 → 分析・可視化 をつないで回す仕組み

演習概要

後期演習②

データパイプラインの構築　

演習概要

  • 本演習では、分析プロセスを自動化するデータパイプラインの構築を行う　
  • 各自任意のプロセスを設定し、全体ないしは部分的な自動化を目指す　
  • アナリスト志望でない学生は、分析以外のプロセスを設定してもよい　

発表の形式

  • 本演習の発表はプレゼン方式で行う　
  • 発表には、次の要素を必ず含めること　

発表に必ず含めること

  1. 対象とするプロセスの全体像　
    • どういった作業フローの、どの部分を自動化するか　
  2. 自動化したパートの説明　
    • 使用した技術・ツールと、その選定理由　
  3. デモンストレーション　
  4. 削減される時間と諸コスト　

演習のマイルストーン

  1. 対象プロセスの設定　
  2. 自動化パートの設定　
  3. 使用する技術の選定　
  4. 実装　
  5. プレゼン準備　
  6. プレゼン
